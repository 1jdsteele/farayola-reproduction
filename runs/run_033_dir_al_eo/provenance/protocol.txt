RUN 033 — Disparate Impact Remover + Adversarial Debiasing + Equalized Odds
(DIR + AL + EO), COMPAS

PURPOSE
Execute and diagnose:

Disparate Impact Remover (DIR)
    -> Adversarial Debiasing / Adversarial Learning (AL)
    -> Equalized Odds postprocessing (EO)

REFERENCE RUNS
- Run 028: DIR + AL
- Run 029: AL + EO

CRITICAL PRE-EO CONTROL
For every seed, the complete DIR -> AL stage must reproduce frozen
Run 028 exactly before EO is applied.

Required Run 028 matches:
- binary prediction SHA256
- continuous AL score SHA256
- confusion matrix
- all five metrics
- score diagnostics

These controls establish that EO is the only new intervention relative to
Run 028.

DIR SETTINGS
- repair_level = 1.0
- sensitive_attribute = race
- training data only
- test data remains unrepaired

DIR REQUIRED BEHAVIOR
- labels unchanged
- race unchanged
- one or more nonprotected training features changed
- original source train/test data objects untouched

AL SETTINGS
Paper-faithful:
- adversary_loss_weight = 0.2
- num_epochs = 50
- batch_size = 128
- debias = True

Library default:
- classifier_num_hidden_units = 200

The hidden-unit parameter is inherited from AIF360 0.6.1 and is not
explicitly passed.

RANDOMNESS
AL receives seed=<current experimental seed>.

No external np.random.seed() or tf.set_random_seed() is added.

EO receives seed=<current experimental seed>.

AL SCORES
The DIR+AL stage supplies continuous classifier scores.

These are preserved and checked against frozen Run 028 before EO.

EQUALIZED ODDS
EqOddsPostprocessing is fit using:
- true labels from the evaluation test set
- DIR+AL predictions from that same test set

It is then evaluated on that same test set.

TEST-SET CALIBRATION CAVEAT
The EO calibration set and evaluation set are the same test set.

This is conventional test-set calibration/evaluation leakage and is
intentionally preserved because it is the established repository-style
postprocessing pathway in this reproduction.

FINAL DIAGNOSTICS
For every seed record:
- number of predictions changed by EO
- whether EO mutates the original DIR+AL labels
- whether EO mutates the original DIR+AL scores
- final prediction SHA256
- final confusion matrix
- final five metrics

RUN 029 COMPARISON
The final DIR+AL+EO output is also compared against frozen Run 029 AL+EO.

This comparison is DIAGNOSTIC ONLY.

Equality is not expected because DIR changed the feature values consumed
by AL in Run 028.

The comparison helps determine whether EO largely erases or preserves the
upstream effect of DIR.

REPRODUCIBILITY
Run 033 is executed twice as independent Python processes, A and B.

Freeze only after exact A/B repeatability is confirmed.
