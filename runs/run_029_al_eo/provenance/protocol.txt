RUN 029 — Adversarial Debiasing + Equalized Odds (AL + EO), COMPAS

PURPOSE
Execute and diagnose:

Adversarial Debiasing / Adversarial Learning (AL)
    -> Equalized Odds postprocessing (EO)

REFERENCE RUN
- Run 026: individual AL

CRITICAL PRE-EO CONTROL
For every seed, the AL stage must reproduce frozen Run 026 exactly before
EO is applied.

Required Run 026 matches:
- binary prediction SHA256
- continuous AL score SHA256
- confusion matrix
- accuracy
- disparate impact
- statistical parity difference
- equal opportunity difference
- predictive equality / false-positive-rate difference

These checks establish that EO is the only new scientific intervention
relative to Run 026.

AL SETTINGS
Paper-faithful:
- adversary_loss_weight = 0.2
- num_epochs = 50
- batch_size = 128
- debias = True

Library default:
- classifier_num_hidden_units = 200

The hidden-unit parameter is inherited from AIF360 0.6.1 and is not
explicitly passed.

RANDOMNESS
AL receives seed=<current experimental seed>.

No external np.random.seed() or tf.set_random_seed() is added.

EO receives seed=<current experimental seed>, consistent with the controlled
EO pathway already used in earlier runs.

AL SCORES
AL supplies continuous prediction scores.

Run 029 preserves and verifies the pre-EO AL prediction and score hashes
against frozen Run 026.

EQUALIZED ODDS
AIF360 EqOddsPostprocessing is fit using:
- true labels from the evaluation test set
- AL predictions from that same test set

It is then evaluated on that same test set.

This reproduces the repository-style postprocessing pathway already used
elsewhere in the reconstruction.

TEST-SET CALIBRATION CAVEAT
This constitutes conventional test-set calibration/evaluation leakage.

The behavior is intentionally preserved for reproducibility rather than
silently redesigned only for AL configurations.

- number of predictions changed by EO
- whether the AL input labels remain unchanged after EO
- whether the AL input scores remain unchanged after EO
- final prediction SHA256
- final confusion matrix
- final five metrics
