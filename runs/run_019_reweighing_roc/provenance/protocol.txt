RUN 019 — Reweighing + Reject Option Classification (PP), COMPAS

PURPOSE
Reproduce and diagnose the released COMPAS Pre-processing ->
Post-processing configuration:

Reweighing (Re) -> Logistic Regression -> Reject Option Classification (ROC)

REFERENCE RUNS
- Run 008: NONE Logistic Regression baseline
- Run 010: meaningful individual Reweighing
- Run 013: individual ROC

REWEIGHING INTEGRATION
AIF360 Reweighing is applied to the training BinaryLabelDataset.

The resulting instance_weights are deliberately NOT supplied to sklearn
LogisticRegression, reproducing the released PP integration pattern.

Therefore:
- Re weights should change;
- features should remain unchanged;
- labels should remain unchanged;
- the pre-ROC classifier should reproduce Run 008 if Re is functionally inert.

ROC INPUT
The Logistic Regression classifier produces hard class predictions.

The ROC prediction BinaryLabelDataset is constructed from those hard
predictions without predict_proba scores.

Therefore its scores should equal hard 0/1 predicted labels, matching the
repository-faithful individual ROC behavior investigated in Run 013.

ROC SETTINGS
- metric_name = "Equal opportunity difference"
- low_class_thresh = 0.3
- high_class_thresh = 0.8
- num_class_thresh = 100
- num_ROC_margin = 50
- metric_ub = 0.05
- metric_lb = -0.05

TEST-SET CALIBRATION
ROC is fit using:
- the evaluation test-set true labels
- predictions on that same test set

and evaluated on the same test set.

This reproduces the repository pathway but constitutes conventional
test-set calibration/leakage.

CONTROLLED BACKBONE
- reconstructed 5,278-row COMPAS dataset
- same 11 predictors
- target two_year_recid
- race protected attribute
- African-American = 0 = unprivileged
- Caucasian = 1 = privileged
- favorable_label = 1
- 70/30 split
- stratify on race
- seeds 101 through 110
- LogisticRegression(solver="lbfgs", max_iter=1000)
- no StandardScaler
- signed fairness metrics retained

EXPECTED DIAGNOSTIC
If both released integration effects reproduce:
1. Re weights change but are unused.
2. Pre-ROC LR matches Run 008 exactly.
3. ROC receives only hard 0/1 scores.
4. ROC may select margin 0 and change zero predictions.
5. Final Re+ROC may match frozen Run 013 exactly.

These are hypotheses to test, not conditions forced by the script.
