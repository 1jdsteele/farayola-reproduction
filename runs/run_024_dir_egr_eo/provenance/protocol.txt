RUN 024 — Disparate Impact Remover + EGR + Equalized Odds (PIP), COMPAS

PURPOSE
Reproduce the three-stage COMPAS pathway:

Disparate Impact Remover (DIR)
    -> Exponentiated Gradient Reduction (EGR)
    -> Equalized Odds (EO)

REFERENCE RUNS
- Run 015: DIR + EGR
- Run 016: EGR + EO

IMPLEMENTATION BASIS
A separate pinned DIR-PIP notebook was not surfaced during the repository
search performed for Run 024.

Therefore Run 024 does not invent a new repository-specific pathway.
Instead it composes two already validated components:

1. The repository-supported DIR -> EGR integration reproduced in Run 015.
2. The repository-supported EGR -> EO postprocessing stage reproduced in
   Run 016.

DIR SETTINGS
- repair_level = 1.0
- sensitive_attribute = race
- applied to training data only
- test data remain unrepaired
- protected race attribute remains unchanged
- labels remain unchanged

EGR SETTINGS
- LogisticRegression(solver="lbfgs", max_iter=1000)
- constraints = DemographicParity
- eps = 0.02
- max_iter = 20
- drop_prot_attr = False

RANDOMNESS
For each diagnostic seed:
- np.random.seed(seed) immediately before EGR fit
- np.random.seed(seed) immediately before EGR prediction
- EO receives seed=seed

These are controlled reconstruction choices and are not claimed to be the
authors' exact unpublished seeds.

CRITICAL PRE-EO CONTROL
For every seed, DIR -> EGR must reproduce frozen Run 015 exactly:
- confusion matrix
- accuracy
- DI
- SPD
- EOD
- PED

This establishes that EO is the only new intervention relative to Run 015.

EO SETTINGS
- AIF360 EqOddsPostprocessing
- unprivileged race = 0
- privileged race = 1
- seed = current experimental seed

TEST-SET CALIBRATION
EO is fitted using:
- true labels from the evaluation test set
- DIR+EGR predictions on that same test set

and evaluated on that same test set.

This preserves the repository-style EO pathway but constitutes test-set
calibration/leakage under conventional independent-holdout evaluation.

RUN 016 COMPARISON
Final Run 024 results are compared with frozen Run 016 EGR+EO as a diagnostic.

Equality is NOT expected or required because DIR changes the training features
before EGR. The comparison measures how much of DIR's effect remains after EO.

CONTROLLED BACKBONE
- reconstructed 5,278-row COMPAS cohort
- 11 predictors
- target two_year_recid
- race protected attribute
- African-American = 0 = unprivileged
- Caucasian = 1 = privileged
- favorable_label = 1
- 70/30 split
- stratify on race
- seeds 101 through 110
- no StandardScaler
- signed fairness metrics retained
- 95% Student-t confidence intervals

PAPER COMPAS DIR+EGR+EO
Reported:
- SPD = 0.037
- DI = 1.097
- EOD = 0.002
- PED = 0.003
- Accuracy = 0.66
