RUN 031 — Reweighing + Adversarial Debiasing + Equalized Odds
(Re + AL + EO), COMPAS

PURPOSE
Execute and diagnose the three-stage pathway:

Reweighing (Re)
    -> Adversarial Debiasing / Adversarial Learning (AL)
    -> Equalized Odds postprocessing (EO)

REFERENCE RUNS
- Run 027: Re + AL
- Run 029: AL + EO

KEY IMPLEMENTATION FINDING
Run 027 established experimentally that:

Re + AL = AL

for every controlled seed, including byte-identical:
- binary prediction SHA256
- continuous AL score SHA256
- confusion matrices
- metrics

Source inspection explains this behavior:
legacy AIF360 AdversarialDebiasing.fit() does not consume
dataset.instance_weights.

Reweighing changes instance_weights but leaves features and labels unchanged.

HYPOTHESIS FOR RUN 031
Because:
1. Re + AL produces the same AL outputs as AL, and
2. EO receives the same seed and same AL predictions as Run 029,

Run 031 is expected to reproduce Run 029 exactly.

This equality is verified explicitly.

REWEIGHING
AIF360 Reweighing is applied to the training BinaryLabelDataset.

Required checks:
- instance weights change
- weights remain finite and positive
- features remain unchanged
- labels remain unchanged
- protected race values remain unchanged

The reweighted BinaryLabelDataset is then passed directly to AL.

No manual sample_weight argument is supplied.

AL SETTINGS
Paper-faithful:
- adversary_loss_weight = 0.2
- num_epochs = 50
- batch_size = 128
- debias = True

Library default:
- classifier_num_hidden_units = 200

The hidden-unit parameter is inherited from AIF360 0.6.1 and is not
explicitly passed.

CRITICAL PRE-EO CONTROL
The Re -> AL stage must reproduce frozen Run 027 exactly for every seed in:
- prediction SHA256
- continuous score SHA256
- confusion matrix
- all five metrics
- score diagnostics

EO
EqOddsPostprocessing is fit using:
- true labels from the evaluation test set
- Re+AL predictions from that same test set

and evaluated on that same test set.

This preserves the established repository-style test-set calibration pathway.

TEST-SET CALIBRATION CAVEAT
EO calibration and final evaluation use the same test set.

This is conventional calibration/evaluation leakage and is intentionally
preserved for reproducibility.

CRITICAL FINAL CONTROL
Run 031 must be compared against frozen Run 029 for every seed in:
- final prediction SHA256
- confusion matrix
- all five final metrics
- number of predictions changed by EO

If those all match, then the nominal Re stage has no downstream effect on
the complete Re -> AL -> EO pipeline.
