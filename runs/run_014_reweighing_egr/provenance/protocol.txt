RUN 014 — Reweighing + Exponentiated Gradient Reduction (PI), COMPAS

PURPOSE
Reproduce the paper's two-stage COMPAS Pre-processing -> In-processing
configuration:

Reweighing (Re) -> Exponentiated Gradient Reduction (EGR)

PARENTS / REFERENCES
- Run 010: individual Reweighing
- Run 011: individual EGR

REPOSITORY PIPELINE
The pinned IF-EA repository:
1. constructs the training BinaryLabelDataset;
2. applies AIF360 Reweighing.fit_transform();
3. obtains a reweighted BinaryLabelDataset;
4. passes that dataset directly to
   AIF360 ExponentiatedGradientReduction.fit();
5. predicts on the untouched test BinaryLabelDataset.

Run 014 reproduces that integration structure.

REWEIGHING
- unprivileged group: race = 0
- privileged group: race = 1
- training data only
- features unchanged
- labels unchanged
- protected attribute unchanged
- instance_weights changed

EGR
- base classifier: LogisticRegression(solver="lbfgs", max_iter=1000)
- constraint: DemographicParity
- eps = 0.02
- max_iter = 20
- drop_prot_attr = False
- prediction randomness controlled using current experimental seed

IMPORTANT IMPLEMENTATION DISCREPANCY
In installed AIF360 0.6.1, the legacy
aif360.algorithms.inprocessing.ExponentiatedGradientReduction.fit(dataset)
implementation extracts:

- dataset.features
- dataset.labels

and calls the underlying sklearn-style EGR model with those values.

It does NOT forward dataset.instance_weights.

Therefore the Reweighing weights generated in stage 1 are present in the
reweighted BinaryLabelDataset but are not consumed by EGR under this API.

This appears to reproduce the structure of the pinned IF-EA repository,
which likewise performs:

re_dataset = RW.fit_transform(dataset_train_bld)
inprocess_algorithm.fit(re_dataset)

Run 014 intentionally preserves this behavior rather than silently
introducing a custom weighted-EGR implementation.

If Run 014 therefore behaves identically to individual EGR, that is a
reproducibility finding, not something to tune away.

A separately labeled diagnostic could later test a custom integration in
which Reweighing weights genuinely influence EGR, but such a procedure
must NOT be called author-faithful without supporting evidence.

RANDOMNESS
EGR predictions are randomized.

For every experimental seed:
- np.random.seed(seed) immediately before EGR fit
- np.random.seed(seed) immediately before EGR prediction

This is a reconstruction reproducibility control and is not claimed to be
an undocumented author procedure.

INTEGRITY / DIAGNOSTIC CHECKS
For every seed:
- Reweighing changes instance weights
- Reweighing does not change features
- Reweighing does not change labels
- Reweighing does not change race
- weights remain positive and finite
- total reweighted sample mass remains equal to training row count
- source test data remain untouched
- installed EGR wrapper is confirmed not to reference instance_weights
- Run 014 metrics are compared with frozen Run 011 individual EGR metrics
