RUN 010 — Individual Reweighing, COMPAS

PURPOSE
Reproduce the paper's individual COMPAS Reweighing fairness intervention
using the standardized Run 008 reconstruction backbone.

PARENT
Run 008 — 10-seed race-stratified NONE Logistic Regression baseline.

PRIMARY SCIENTIFIC CHANGE
Apply AIF360 Reweighing to TRAINING DATA only and pass the resulting
instance weights to LogisticRegression.fit(..., sample_weight=...).

REWEIGHING SETTINGS
- protected attribute: race
- unprivileged group: race = 0
- privileged group: race = 1
- favorable label: 1
- unfavorable label: 0
- fit_transform applied to training dataset only
- resulting instance_weights are supplied to the classifier
- features are not modified
- labels are not modified
- test set remains untouched

HELD CONSTANT FROM RUN 008
- reconstructed 5,278-row COMPAS dataset
- same 11 predictors
- target: two_year_recid
- protected attribute: race
- African-American = 0 = unprivileged
- Caucasian = 1 = privileged
- favorable_label = 1
- unfavorable_label = 0
- 70/30 train/test split
- shuffle = True
- stratify on race
- diagnostic seeds 101 through 110
- LogisticRegression(max_iter=1000)
- same AIF360 fairness metrics
- signed fairness metrics preserved
- same aggregate statistics and 95% t confidence intervals
- no StandardScaler

IMPORTANT RECONSTRUCTION CHOICES
- Seeds 101-110 are diagnostic seeds and are NOT claimed to be the authors'
  exact ten seeds.
- Race stratification operationalizes the paper's description, despite the
  released repository using stratify=y.
- LogisticRegression(max_iter=1000) is a reconstruction stability choice.
- The AIF360 Reweighing instance weights are explicitly passed to
  LogisticRegression via sample_weight so that the intervention actually
  affects model fitting.
- Some released repository pathways appear to construct reweighted data
  without clearly passing the resulting instance weights to Logistic
  Regression. Run 010 uses the operationally meaningful AIF360 reweighing
  procedure and records this as a reconstruction choice.

INTEGRITY CHECKS
For every seed:
- row count unchanged
- feature values unchanged
- labels unchanged
- race unchanged
- resulting weights are finite and positive
- resulting weights are not all equal to 1
- test dataframe remains untouched
