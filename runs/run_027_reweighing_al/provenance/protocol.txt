RUN 027 — Reweighing + Adversarial Debiasing (Re + AL), COMPAS

PURPOSE
Test the two-stage COMPAS pathway:

Reweighing (Re)
    -> Adversarial Debiasing / Adversarial Learning (AL)

REFERENCE RUN
- Run 026: individual AL

SCIENTIFIC QUESTION
Does Reweighing actually affect legacy AIF360 AdversarialDebiasing?

SOURCE-LEVEL FINDING
The exact installed AIF360 0.6.1 implementation of:

AdversarialDebiasing.fit()

does not reference:

dataset.instance_weights

Reweighing's primary intervention is to change those instance weights.

Therefore there is a strong implementation-level hypothesis that:

Re + AL = AL

under the released legacy pathway.

This equality is NOT imposed on Run 027.
It is measured experimentally.

REWEIGHING
AIF360 Reweighing is applied to the training BinaryLabelDataset using:

- race 0 = unprivileged
- race 1 = privileged

Required diagnostics:
- instance weights must change
- all weights must remain finite and positive
- features must remain unchanged
- labels must remain unchanged
- protected race values must remain unchanged

The resulting reweighted BinaryLabelDataset is passed directly to AL,
matching the released author's Re + AL notebook structure.

No manual sample_weight argument is supplied.

AL SETTINGS
Paper-faithful:
- adversary_loss_weight = 0.2

- batch_size = 128

Library-default:
- classifier_num_hidden_units = 200

passed to the constructor.
