RUN 023 — Reweighing + EGR + Reject Option Classification (PIP), COMPAS

PURPOSE
Reproduce and diagnose:

Reweighing (Re)
    -> Exponentiated Gradient Reduction (EGR)
    -> Reject Option Classification (ROC)

REFERENCE RUNS
- Run 011: individual EGR
- Run 014: Re + EGR
- Run 017: EGR + ROC

REWEIGHING / EGR FINDING
Run 014 established that AIF360 0.6.1's legacy
ExponentiatedGradientReduction.fit() extracts features and labels from the
BinaryLabelDataset but does not consume dataset.instance_weights.

Therefore the Reweighing stage changes instance_weights, but those weights
are not expected to influence EGR in the released pathway.

RUN 023 TEST
For each seed:
1. Apply Reweighing to training data.
2. Verify weights change.
3. Verify features, labels, and race do not change.
4. Pass the reweighted BinaryLabelDataset directly to EGR.
5. Do NOT manually pass sample weights.
6. Predict on the untouched test dataset.
7. Verify pre-ROC EGR reproduces frozen Run 011 exactly.
8. Apply ROC to the EGR prediction dataset.
9. Compare final output against frozen Run 017 EGR+ROC.

If Re is functionally inert, Run 023 should reproduce Run 017 exactly.

EGR SETTINGS
- LogisticRegression(solver="lbfgs", max_iter=1000)
- constraints = DemographicParity
- eps = 0.02
- max_iter = 20
- drop_prot_attr = False

EGR SCORE NUMERICAL TOLERANCE
Run 017 showed machine-precision PMF roundoff:
- scores as high as 1.0000000000000002
- PMF entries as low as approximately -2.22e-16
- PMF row sums remained 1.0

Run 023 therefore permits a score-bound tolerance of 1e-12.
Raw scores are preserved without clipping.

ROC SETTINGS
- metric_name = "Equal opportunity difference"
- low_class_thresh = 0.3
- high_class_thresh = 0.8
- num_class_thresh = 100
- num_ROC_margin = 50
- metric_ub = 0.05
- metric_lb = -0.05

Unlike LR-based ROC Runs 013, 019, and 021, ROC receives EGR's nonbinary
scores rather than hard 0/1 scores.

TEST-SET CALIBRATION
ROC is fit using true test labels and EGR predictions/scores on that same
test set, and evaluated on that same test set.

This preserves the released pathway but constitutes conventional test-set
calibration/leakage.

RANDOMNESS
For every diagnostic seed:
- np.random.seed(seed) immediately before EGR fit
- np.random.seed(seed) immediately before EGR prediction

ROC itself is deterministic under these settings.

CONTROLLED BACKBONE
- reconstructed 5,278-row COMPAS cohort
- 11 predictors
- target two_year_recid
- race protected attribute
- African-American = 0 = unprivileged
- Caucasian = 1 = privileged
- favorable_label = 1
- 70/30 race-stratified split
- diagnostic seeds 101 through 110
- no StandardScaler
- signed fairness metrics retained
- 95% Student-t confidence intervals
